# 🚀 Deresa – Smart Task Management App

> A simple, clean and responsive task management application designed to help users organize, prioritize and track their daily tasks efficiently.

---

## ✨ Overview

**Deresa** is a lightweight and user-friendly task management web application built using **HTML, CSS and JavaScript**.

It allows users to create, manage, prioritize and track their tasks through a simple and clean interface.

The project focuses on making everyday task management easier with features such as **priority levels, due dates, task completion tracking, editing, deletion and persistent local storage**.

---

## 🎯 Features

### 📝 Task Management
- Add new tasks quickly
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Track pending and completed tasks

### 🚦 Priority Management
Tasks can be assigned different priority levels:

- 🔴 High
- 🟠 Medium
- 🔵 Low

### 📅 Due Date Tracking

Each task can have a due date with automatic status:

- 🔴 Overdue
- 🟠 Due Today
- 🟢 Upcoming
- ⚪ No Due Date
- ✅ Completed

### 🔍 Search & Filtering
- Search tasks easily
- Filter tasks based on their status
- Organize tasks efficiently

### 💾 Local Storage

Tasks are stored using the browser's **Local Storage**, so data remains available even after refreshing the page.

### 📊 Task Counter

The application displays the current task count and pending tasks.

### 📱 Responsive Design

The interface is designed to work across:

- 💻 Desktop
- 💻 Laptop
- 📱 Mobile
- 📟 Tablet
